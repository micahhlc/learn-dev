Type: Describes the kind of change you’re making. Common types are:
	•	feat: A new feature
	•	fix: A bug fix
	•	docs: Documentation changes
	•	style: Formatting, missing semicolons, etc. (code doesn’t change)
	•	refactor: Code changes that neither fix a bug nor add a feature
	•	test: Adding or modifying tests
	•	chore: Miscellaneous tasks (e.g., updating dependencies)
	
2.	Scope (optional): Specifies the part of the project affected by the commit. For example, a specific module or component.
	•	Example: feat(auth): add login page
	
3.	Subject: A brief description of the change in the present tense. Keep it short (usually under 50 characters).
	•	Example: fix(auth): correct login form validation
